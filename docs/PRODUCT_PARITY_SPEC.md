# JournalCollage 产品对齐规格

> 状态：实施基线  
> 更新日期：2026-09-10  
> 适用范围：Expo + React Native + React Native Skia 的 iOS 首发产品层；Android 共享 Editor 的后续实现。

## 1. 目标与信息优先级

目标是让 iOS 产品的页面结构、视觉节奏、工具入口与操作流程对齐当前已上线小程序，同时保持跨端 Editor 架构。对齐不等于复制 WXML/WXSS、微信系统栏或 Canvas 实现；iOS 使用原生安全区、键盘、相册和分享能力表达同一产品语义。

发生冲突时，按以下顺序决策：

1. `小程序截图/IMG_7586.PNG` 至 `IMG_7599.PNG`：当前视觉金样。
2. `miniprogram-spike/miniprogram/`：当前流程、状态机、素材和数据行为。
3. `docs/MINIPROGRAM_RECENT_UPDATES_IOS_ALIGNMENT.md`：相对旧 Swift 项目的功能增量与已修复行为。
4. `docs/MINIPROGRAM_MVP_PLAN.md`：用户流程、异常分支和产品范围主规格。
5. `PROJECT_MEMORY.md` 与 `docs/PROTOTYPE_COMPONENT_MAPPING.md`：品牌原则和历史设计依据。
6. `iosproject/`：效果算法、历史行为和测试参考，**不是**产品 UI 的视觉依据。

## 2. 当前冻结的产品基线

### 导航

- 当前产品为 3 个主 Tab：**创作、素材、我的**。
- 灵感页面与配置可以保留为可路由能力，但当前不显示在首发 Tab Bar；恢复前需有新的小程序金样和明确产品决定。
- 编辑器以全屏工作区呈现，隐藏 Tab Bar；退出后回到其来源页面或来源上下文。

### 编辑器主状态

| 状态 | 触发 | 固定 UI | 退出 |
| --- | --- | --- | --- |
| 空创作页 | 无活动 Draft | 新拼贴、添加照片、空白画布、素材包入口、效果体验、最近草稿 | 新建或恢复 Draft |
| 普通编辑 | 有 Draft、未选中图层 | 顶栏、画布、七项主工具栏 | 点选图层或离开编辑器 |
| 已选中图层 | 点选可编辑图层 | 细黑选框、锁定/替换控制、图层底部工具面板 | 点空白或完成 |
| 工具局部模式 | 打开剪刀等局部工具 | 画布保留，显示悬浮子工具 | 取消、完成或返回 |
| 工具 Sheet | 素材、背景、文字等 | 半透明遮罩、白色底部面板、短 handle | 下滑、点遮罩、取消或完成 |
| 全屏工具模式 | 裁切、涂抹剪、压花 | 独立顶栏、工具预览与专属底部控制 | 取消或确认 |

### 主工具栏

当前工具顺序固定为：

`图片 / 素材 / 背景 / 文字 / 剪刀 / 压花 / 画笔`

- 胶带通过“素材”或图层组合效果添加，不单列为主工具。
- 形状能力通过“压花”入口表达，不单列为主工具。
- 每个工具使用低饱和实体感图标与短标签；面板内操作使用现代线性图标。

## 3. 视觉规范

### 品牌原则

- 现代、克制、轻纸感；UI 退后，画布与素材成为主角。
- UI 只使用黑、白、灰和极浅暖白；纸张、胶带、印章、图片效果可以使用材质色彩。
- 避免商城感、可爱 App 外壳、厚重拟物、毛玻璃、蓝色系统主按钮和大面积纸纹。
- 素材可以可爱、复古或高饱和；应用框架本身必须保持安静。

### Token

| 用途 | 值 |
| --- | --- |
| Ink / 主文字 / 主按钮 | `#111111` |
| 次级文字 | `#6F6F6F` |
| 三级文字与未选中 Tab | `#9A9A9A` |
| 页面背景 | `#FAFAF8` |
| 面板与工具栏 | `#FFFFFF` |
| 弱表面与未选中 chip | `#F7F7F5` |
| 轻边界 | `#E8E6E1` |
| 分隔线 | `#ECEAE5` |
| 画布纸面 | `#FDFDFB` |
| 素材辅助色 | 胶带黄 `#E9D28A`、纸张米 `#EFE7D8`、鼠尾草 `#8C9A8D`、印章红 `#D94A38` |

### 布局规则

- 页面横向安全边距以 16–20 pt 为基准；编辑画布和全屏工具模式可使用更紧凑边距。
- 普通卡片圆角 6–8 pt；工具栏和 Sheet 可为 18–24 pt；禁止将所有内容做成大圆角卡片。
- 编辑画布使用轻纸面、细边界与柔和大阴影；画布四周保持充足留白。
- 顶栏高度、Tab Bar 高度和 Sheet 底部避让必须统一基于 iOS Safe Area 计算，不能复制微信胶囊和状态栏位置。
- UI 使用系统字体；手写/复古字体只在画布文字、素材标题或素材内容中使用。

### 本地化

- 英文是美区首发基线，简体中文为完整的第二语言；两种语言保持相同的信息层级、功能入口和状态数量。
- 英文应按产品语义撰写，不逐字翻译中文；工具、按钮和错误提示保持短句，避免挤压工具栏与 Sheet。
- 本地化属于 `apps/mobile` 产品层，`editor-core`、`editor-renderer`、`asset-system` 不依赖翻译运行时，也不保存显示文案。
- 所有用户可见的产品 UI 使用稳定 key；每个 key 必须有 `en` 和 `zh-Hans` 值。素材内容、用户输入和远程素材元数据按自身内容语言展示，不强制翻译。
- 解析顺序固定为：设备 `zh-Hans`/中文区域使用简体中文；其他区域使用英文；任意缺失翻译回退到英文文案。
- 生产环境严禁将 key 本身作为用户可见的回退文本；出现 `layer.action.up`、`editor.export.button` 等字符串视为 P0 发布缺陷。开发环境记录缺失 key，以便测试发现问题。
- 本地化测试包括：key 两语言完整性校验、未知 locale 回退英文、缺失翻译回退英文、两种语言的关键页面截图回归。

## 4. 页面与流程规格

### 创作 Tab

来源：`IMG_7594.PNG`、`pages/create/index.wxml`。

- 空态标题为“新拼贴”语义；顶部不能叠加无关营销副标题。
- 主照片入口为页面最大操作区，中心为黑色圆形加号和“添加照片”。
- 下方并列“从空白画布开始”与“从素材包开始”。
- 展示横向效果体验内容；它是轻启动灵感，不应变成模板商城。
- 最近草稿为横向缩略图；点击恢复 Draft，而不是仅打开导出图片。
- 照片导入成功：创建或更新 Draft → 创建 `user://image/...` 资源 → `layer.add` → 选中新图层 → 进入普通编辑态。

### 编辑器顶栏与画布

来源：`IMG_7586.PNG`、`IMG_7587.PNG`、`IMG_7590.PNG`。

- 顶栏顺序：返回、比例 Pill、撤销、重做、黑色“导出”按钮。
- 画布使用逻辑坐标，默认比例为 3:4；屏幕布局仅通过 Viewport 计算适配。
- 预览、缩略图、导出使用同一 Renderer Scene；选中框、控制柄、参考线和工具 UI 均不导出。
- 撤销、重做和保存状态由 Command 历史与 Draft 持久化驱动，不由页面局部状态伪造。

### 素材

来源：`IMG_7587.PNG`、`IMG_7595.PNG`、`IMG_7596.PNG`、`IMG_7597.PNG`、`IMG_7599.PNG`。

- 编辑器素材 Drawer：标题、查看全部、横向分类 chip、紧凑网格；用于快速添加。
- 素材 Tab 分类固定为：推荐、收藏、贴纸、胶带、便签、主题混装、相框、内芯纸。目录来源只有一个，Tab 与 Drawer 禁止各自维护分类。
- 素材包列表为双列内容预览，主视觉是素材纸包中的真实内容；不展示数量、价格、购买按钮或长描述。
- 素材包详情为可滚动“散落素材纸”，支持多选；仅选中至少一个素材后启用“添加到画布”。
- 从素材页或 Drawer 添加时，使用稳定 `asset://pack/...` 引用和 `layer.add` Command；保留创作来源 Draft，上下文完成后回到编辑器。
- 资源加载需支持 bundle、缓存、远程 URL 与失败占位，但 Draft 不能保存 URL、缓存路径或 Skia 对象。

### 背景

来源：`IMG_7588.PNG`。

- 作为主工具栏独立入口。
- Sheet 分类包括纯色、波点、格纹、纸感、图案。
- 背景变更通过 `draft.background.set` 类 Command 写入；背景资源也须用稳定资源引用表达。
- 不将背景图当作普通可选中图层，也不将面板状态写入 Draft。

### 文字

来源：`IMG_7589.PNG`。

- 添加文字后进入键盘联动的文字编辑模式；画布保持可见，文字框保持选中。
- 面板包含字体、样式/变体、颜色、大小、对齐、底色、透明度。
- 字体保存 `fontId` 与 `fontVariantId`；字体资源按需解析、缓存并提供失败回退，绝不保存 iOS/Android 字体名称。
- 文本内容、样式和变换分别通过 Command 更新；键盘每次输入不得生成无界历史记录，应在编辑会话确认或防抖后合并。

### 剪刀

来源：`IMG_7590.PNG` 与近期更新文档。

- 子工具为：直线剪、花边剪、涂抹剪、主体剪。
- 未选中支持图层时，入口不可执行并给出非打扰式提示。
- 直线/花边剪生成稳定 clip-path 或 mask 语义；涂抹剪保存语义笔画/alpha mask；主体剪生成 `generated://` 结果资源。
- 取消、重复剪切和导出后均不得残留临时图层、遮罩或重复图层。

### 已选中图层与效果

来源：`IMG_7591.PNG`、`IMG_7593.PNG`。

- 选中框为细黑线和小方控制点；提供锁定与替换图片控制。
- 底部面板为高密度图标网格：上移、下移、复制、删除、裁切、阴影、透明度、圆角、描边、效果、剪刀、压花。
- 效果面板分为结构与质感：撕边、贴住、浮起、蕾丝框等结构效果；蓝晒印刷、丝网印、图鉴、像素绣、马蒂斯等质感效果。
- 每种效果必须使用 `{ id, type, version, enabled, params }` 语义，分别支持 Renderer、导出、撤销和迁移；禁止用平台私有滤镜对象持久化。

### 画笔

来源：`IMG_7592.PNG`。

- 画笔是独立的底部专用面板，不应挤进通用效果 Sheet。
- 首批选项：笔刷类型、颜色、粗细、撤销上一笔、清空、取消、完成。
- Draft 保存笔画数据（brush ID、点列、尺寸、间距、抖动、seed、颜色）；Renderer 缓存 Path/Picture/纹理 atlas。

### 压花

来源：`IMG_7593.PNG`。

- 使用黑色沉浸式全屏编辑模式：取消、标题、完成、图片预览、遮罩控制点和底部形状选择。
- 形状包括圆形、方形、心形、星形、标签及后续素材形状。
- 支持非等比调整、固定比例切换、恢复初始蒙版；重复进入同一图层必须稳定。
- 压花蒙版作为正式 mask 语义保存，能与裁切、描边、剪刀和导出组合。

### 我的

来源：`IMG_7598.PNG`。

- 页面包括最近草稿、清理缓存和反馈；不做社区、账号主页或完整作品管理。
- 草稿使用真实缩略图和本地元数据；删除或清理缓存需明确区分草稿、导出文件和可安全删除的缓存。
- 美区版本的反馈入口替换为正式支持渠道，但保持卡片层级和轻量表达。

## 5. 跨端架构约束

| 层 | 责任 | 禁止事项 |
| --- | --- | --- |
| `apps/mobile` | 页面、导航、Sheet、键盘、安全区、相册、分享、触觉与加载状态 | 直接突变 Draft；自行绘制导出版本 |
| `editor-core` | Draft、Layer、Effect、Mask、Command、Undo/Redo、几何、命中、迁移、校验 | 依赖 React、Skia、Expo、平台文件路径 |
| `editor-renderer` | 由 Draft 构建 Skia Scene；预览、缩略图、导出复用规则 | 修改 Draft 或保存 UI Overlay |
| `asset-system` | 素材目录、资源 ID、下载、缓存、字体和 AssetResolver | 向 Draft 泄露 URL、缓存文件路径 |
| Native Adapter | 相册、分享、远程分割/图像处理、平台专属编码 | 持有编辑器业务状态 |

## 6. 实施与验收顺序

### P1：产品骨架与基础编辑闭环

1. 三 Tab、创作空态、最近草稿与全屏编辑器路由。
2. 顶栏、画布、七项主工具栏、照片导入、基础图层手势与自动保存。
3. 素材 Tab、素材 Drawer、背景 Drawer、文字面板、真实 Asset Catalog。
4. 选中图层面板、基础裁切、阴影、透明度、圆角、描边、撕边。
5. PNG/JPEG 导出、保存相册、分享和失败状态。

### P2：差异化编辑器

1. 花边/涂抹/主体剪。
2. 压花、图像笔刷、结构/质感效果。
3. 字体变体、远程字体按需加载、远程素材缓存。
4. 素材收藏、素材详情多选与效果体验入口。

### 逐状态验收

- 每个 P1/P2 状态建立对应截图金样、iOS 截图、交互录屏和差异说明。
- 先验收信息层级、状态切换和工具顺序；再验收字体、间距、阴影、圆角和动效。
- 每个 Command 做单元测试；每种效果做预览/缩略图/导出一致性测试。
- 至少验证：新 iPhone、普通 iPhone、Android Phone、Android Tablet；Android 验证共享 Editor，不阻塞 iOS 首发。
- 30 层真实素材连续交互；高频手势不触发 React 全量重渲染；草稿恢复与导出无明显视觉差异。

## 7. 已知待确认项

- 素材 8 分类是否已冻结，以及分类 logo 的最终字体与回退方案。
- Cloudflare CDN 的版本、缓存 TTL、刷新与鉴权策略。
- 哪些字体获得 iOS 远程下载/缓存授权。
- 主体剪与涂抹剪服务的输入限制、鉴权和结果格式。
- 灵感 Tab 是否长期移除，或在后续版本重新作为主入口。
