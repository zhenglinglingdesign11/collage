## 2. 素材相关更新

### 素材分类调整

小程序素材页和创作页素材抽屉的分类已经不只是早期的泛分类，当前可见分类包括：

- 推荐
- 收藏
- 贴纸
- 胶带
- 便签
- 主题混装
- 相框
- 内芯纸

iOS 对齐时，素材页和编辑器内的素材抽屉都应使用同一套分类逻辑，避免一端叫“纸张 / 票据 / 纹理”，另一端叫“便签 / 主题混装 / 内芯纸”。

### 素材包收藏

小程序已经有素材包收藏能力，并有独立的“收藏”分类。iOS 后续需要支持素材包收藏状态，至少在素材包详情页和素材列表页保持一致。

### 素材详情多选添加

素材详情页支持选择多个素材，再统一添加到画布。iOS 端不应只做单个素材点击即返回，后续要保留批量选择和批量添加的体验。

### 素材详情重叠优化

小程序对素材详情页的重叠问题做了优化，核心表现是素材在详情纸面中更稳定地排布，减少素材之间互相压住，也避免封面、素材图、底部添加区域互相遮挡。iOS 端实现素材包详情时，需要同步关注长素材、窄素材、横向素材和多素材包的布局表现。

### 从素材包开始

创作空状态保留“从素材包开始”入口；从编辑器内打开素材页时，也需要保留当前草稿上下文，添加素材后回到创作页继续编辑。

### 接入 Cloudflare 加载远程素材

小程序素材加载已接入 Cloudflare 远程资源。iOS 后续素材包不应只按本地 bundle 设计，需要支持远程素材、远程封面、缓存和加载失败占位。

### 创建素材处理工具

小程序新增了素材处理工具，用于素材包生产、压缩或配置生成。iOS 端后续应尽量复用处理后的素材产物和配置结果，避免两端素材尺寸、命名、分类和预览图不一致。

## 3. 字体与文字工具更新

### 新增字体

小程序当前字体表中已经新增多组字体，并按 `fontId` 和 `groupId` 管理。已知字体包括：

- Codystar：常规、细体
- Gemini：常规
- Kelsi：常规、填充
- Little Kids：常规
- Melted Ideas：常规
- Mountains：常规、加粗
- Sweet Dreams：常规
- 小濑字体：常规
- 新愚公迷茫体：常规
- 苦累娃圆体：常规
- 轻松手写体：常规

iOS 对齐时，文字工具里的字体列表、字体预览、字体变体需要尽量与小程序保持一致。草稿中应继续以稳定字体 ID 记录用户选择，而不是只记录平台字体名称。

### 字体远程加载

小程序字体资源已经改为通过远程地址加载，当前字体基础地址为 `https://assets.zllarchi.site/fonts`。iOS 端需要考虑同样的远程字体来源、缓存、加载失败兜底，以及字体授权问题。

### 字体按需加载

小程序字体不是一次性全部内置加载，而是按需加载远程字体。iOS 端也需要避免首包过大和启动时加载过多字体，应按文字面板使用、画布渲染或草稿恢复场景按需加载。

### 素材分类 logo 字体远程加载

截图中单独提到“素材分类 logo 字体远程加载”，这意味着素材分类区域不仅有分类文案变化，还涉及标题 / logo 字体的视觉更新。iOS 素材页需要同步该视觉表现，至少要保证分类 logo 字体风格、字号层级和加载兜底一致。

### 文字样式能力增强

小程序文字面板当前包含：

- 字体
- 字体样式 / 变体
- 颜色
- 大小
- 底色
- 透明度

其中“样式”是字体工具面板中新增加的独立项，用于承载同一字体组下的不同变体。iOS 后续对齐文字工具时，应把这些作为同一组文字编辑能力迁移，而不是只支持输入文字和基础字号。

## 4. 剪刀、分割与图层工具更新

### 剪刀工具入口更完整

小程序剪刀面板当前包含：

- 直线剪
- 花边剪
- 涂抹剪
- 主体剪

其中“波浪剪”文案已调整为“花边剪”。iOS 端后续需要同步入口命名，避免用户跨端看到不同工具名称。

### 修复剪切工具显示多余图层

小程序已修复剪切工具显示多余图层的问题。iOS 对齐时，需要重点检查剪切确认、取消、连续剪切和导出场景，确保不会出现临时遮罩层、旧图层或重复图层残留。

### Cloudflare 接入分割小工具

小程序分割小工具已经接入 Cloudflare。iOS 后续如果接入主体分割、涂抹分割或类似能力，应对齐小程序的处理入口、结果加载方式和失败重试体验。

### 图层效果更丰富

小程序图层工具栏已经包含更多效果类操作：

- 裁切
- 阴影
- 透明度
- 圆角
- 描边
- 撕边
- 剪刀
- 压花

iOS 首版可以分阶段实现，但功能清单和最终体验需要按这组能力对齐。

### 压花工具优化

当前小程序压花工具支持形状选择和遮罩区域调整，并且已经优化过非等比宽高调整。iOS 后续实现压花时，需要支持类似的形状预览和可调整区域，而不是只做固定大小的图层效果。

### 压花相关 Bug 优化

小程序修复了压花自由调整比例和第二次压花异常的问题。iOS 后续实现时，需要特别验证：

- 压花遮罩可以自由调整宽高比例。
- 第二次进入压花或对已压花图层再次压花时，不出现图层状态错乱。
- 压花后的图层继续参与剪切、描边、导出时表现正常。

### 主工具栏增加画笔

小程序主工具栏已出现“画笔”入口。即使 iOS 不在首版完整实现，也建议在功能规划中预留画笔 / 装饰笔刷能力。

### 画笔面板展示优化

小程序修复了画笔面板展示问题。iOS 对齐时需要关注画笔面板的打开状态、底部安全区、选项展示和与主工具栏 / 图层工具栏之间的切换关系。

## 5. 背景能力更新

小程序编辑器主工具栏已包含“背景”入口，并支持背景分类和背景卡片选择。iOS 端需要把背景作为独立工具对齐，而不是把背景混在素材或纸张里处理。

## 6. 主导航更新

### 暂时去掉灵感 tab 页

小程序近期暂时去掉了灵感 tab 页。iOS 后续对齐时，需要确认当前阶段是否也隐藏灵感入口，避免 iOS 继续保留旧的 4 tab 导航而与小程序当前体验不一致。

## 7. CDN 与缓存更新

### Cloudflare 缓存优化

小程序对 Cloudflare 缓存做了优化，影响范围不只是图片素材，也可能包括字体、灵感图、工具结果图。iOS 端后续要统一远程资源缓存策略，保证资源能更新、能复用缓存、失败时有占位或重试。

### 素材远程资源解析

小程序素材资源已经支持本地路径、远程 URL、云文件临时 URL 等来源。iOS 对齐时，素材配置需要保留远程资源能力，不能只按本地 bundle 素材设计。

## 8. iOS 后续对齐优先级

P0 建议优先对齐：

- 素材分类调整
- 素材详情布局不重叠
- 剪切工具不出现多余图层
- Cloudflare / 远程素材缓存基础策略
- 背景工具入口
- 暂时隐藏灵感 tab 的导航调整
- 压花自由调整比例和二次压花稳定性

P1 建议继续对齐：

- 新增字体列表和字体变体
- 素材分类 logo 字体远程加载
- 字体按需加载
- 素材包收藏
- 素材详情多选添加
- 文字样式完整面板
- 剪刀工具完整入口
- 画笔入口和画笔面板展示

P2 可后续增强：

- 分割小工具 Cloudflare 接入
- 主体剪 / 涂抹剪完整效果
- 压花高级调整
- 画笔 / 装饰笔刷
- 素材处理工具链继续完善

- Cloudflare CDN 域名、缓存 TTL、版本刷新规则是否已固定。
- 分割小工具的正式接口、鉴权、输入限制和结果格式。
- 灵感 tab 是临时隐藏还是后续长期移除。
