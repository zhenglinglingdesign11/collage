# 小程序 MVP 开发计划与 iOS 复用策略

更新时间：2026-07-08

本文档沉淀本轮会话中关于“先小程序 MVP，后续美区 iOS”的产品范围、核心流程、技术验证 Spike、开发计划和跨端复用策略。后续跨会话继续推进时，优先读取本文档和根目录 `PROJECT_MEMORY.md`。

## 1. 路线结论

建议路线：

```text
技术 Spike
→ 小程序 P0 MVP
→ 数据验证
→ 美区 iOS 前置验证
→ iOS 原生 / React Native 正式开发
```

核心判断：

- 小程序先验证产品机制：上传照片、拼贴编辑、素材差异化、草稿、导出、分享意愿。
- iOS 后验证海外市场、付费能力和高质量创作体验。
- 小程序不直接作为 iOS 代码复用对象；真正复用的是 Draft JSON、Layer schema、素材配置、灵感配置、API、埋点、视觉规范。
- H5 原型定位为高保真交互与视觉参考，不继续作为生产工程深做。

## 2. MVP 功能范围冻结

### MVP 目标

用户能在 3-5 分钟内完成：

```text
打开小程序
→ 添加照片
→ 调整画面
→ 添加素材 / 文字
→ 自动保存草稿
→ 导出到相册
```

验证重点：

- 用户是否愿意上传照片进行拼贴。
- 胶带、撕边、纸张、素材纸包是否能形成差异化。
- 用户是否愿意保存或分享成品。
- 小程序 canvas、触控、导出能力是否足够支撑体验。

### P0 必须做

创作页：

- 新建拼贴。
- 选择画布比例：`3:4`、`1:1`、`9:16`。
- 从相册添加图片。
- 图片基础操作：移动、缩放、旋转。
- 图层选中、删除、复制。
- 撤销/重做基础版。

素材能力：

- 素材页。
- 素材包列表。
- 素材包详情。
- 添加纸张、胶带、贴纸到画布。
- 素材资源本地 / CDN 配置化。

基础文字：

- 添加文字。
- 编辑文字内容。
- 调整文字位置。
- 删除文字。
- 基础字号或预设样式。

灵感页：

- 灵感图瀑布流。
- 点击查看大图。
- 不进入创作页。
- 灵感图片配置化。

我的页：

- 最近草稿。
- 清理缓存。
- 不展示收藏素材。

草稿：

- 本地自动保存。
- 最近草稿列表。
- 点击草稿继续编辑。
- 草稿保存为图层 JSON，不只保存截图。

导出：

- canvas 合成最终图片。
- 保存到相册。
- 授权失败提示。
- 导出失败兜底提示。

基础埋点：

- 新建拼贴。
- 添加图片。
- 添加素材。
- 添加文字。
- 保存草稿。
- 导出成功。
- 导出失败。
- 灵感大图点击。

### P1 纳入计划但不阻塞上线

高级文字样式：

- 字体预设。
- 字号调节。
- 文字颜色。
- 文字背景。
- 透明度。
- 旋转。
- 多行文本。

剪刀功能：

- 进入剪刀模式。
- 选择裁剪样式：直线、波浪、撕边。
- 对选中图片或素材生成裁剪效果。
- 可取消剪刀模式。

其他 P1：

- 导出后分享。
- 草稿预览图增强。
- 素材懒加载、分类、常用素材排序。

### P2 暂缓

- 素材收藏。
- 素材商城。
- 搜索素材。
- 模板一键套用。
- AI 生成素材 / 排版。
- 云端草稿多设备同步。
- 会员体系。
- 复杂形状 / 压花工具。
- 自定义贴纸上传。
- 社区发布。
- 评论 / 点赞。
- 个人主页。
- iOS 正式版本。

### 明确不做

- 不做素材商城。
- 不做复杂账号体系。
- 不做社区内容流。
- 不做多人协作。
- 不做云端模板市场。
- 不做复杂路径级自由裁剪。
- 不做 WebView 包壳编辑器。
- 不做完整 iOS 版本。

## 3. 页面范围

小程序保留 4 个主 tab：

1. 创作
   - 新建拼贴。
   - 编辑画布。
   - 添加图片 / 素材 / 文字。
   - 导出入口。

2. 素材
   - 素材包列表。
   - 素材包详情。
   - 添加到画布。

3. 灵感
   - 瀑布流图片。
   - 大图预览。

4. 我的
   - 最近草稿。
   - 清理缓存。

## 4. 核心用户流程

### 主流程：从照片开始

```text
进入小程序
→ 默认进入「创作」
→ 空画布轻启动状态
→ 点击「添加照片」
→ 调起相册
→ 用户选择图片
→ 创建默认 3:4 画布
→ 图片进入画布
→ 用户拖拽 / 缩放 / 旋转图片
→ 添加素材 / 胶带 / 文字
→ 自动保存草稿
→ 点击导出
→ 生成预览
→ 保存到相册
→ 成功提示
```

关键埋点：

- `create_enter`
- `add_photo_click`
- `add_photo_success`
- `edit_layer_transform`
- `draft_auto_save`
- `export_click`
- `export_success`
- `export_fail`

### 创作页状态

空画布状态：

- 显示「新拼贴」。
- 选择比例：`3:4`、`1:1`、`9:16`。
- 添加照片。
- 从素材包开始。
- 最近草稿。

普通编辑状态：

- 顶部显示返回 / 已保存 / 撤销 / 重做 / 导出。
- 中间显示拼贴画布。
- 底部显示主工具栏。
- 用户可添加图片 / 素材 / 胶带 / 文字 / 剪刀 / 形状。

图层选中状态：

- 用户点击画布图层。
- 图层出现选中框。
- 显示控制点。
- 底部主工具栏切换为图层工具栏。
- 用户可复制 / 删除 / 上移 / 下移 / 调整透明度等。
- 点击空白或完成后回到普通编辑状态。

### 添加图片流程

```text
点击「图片」
→ 打开图片工具面板
→ 选择「从相册选择」
→ 调起 wx.chooseMedia
→ 获取图片本地路径
→ 获取图片宽高信息
→ 生成 image layer
→ 插入画布中央
→ 自动选中新图层
→ 自动保存草稿
```

异常分支：

- 用户取消选择：回到编辑状态，不提示或轻提示。
- 读取图片失败：提示「图片添加失败，请重试」。
- 图片过大：压缩或限制导入尺寸，避免 canvas 卡顿。

### 添加素材流程

路径 A：创作页素材抽屉。

```text
编辑状态
→ 点击主工具栏「素材」
→ 打开底部素材抽屉
→ 展示常用素材 / 分类素材
→ 点击素材
→ 素材进入画布
→ 自动选中新素材
→ 自动保存草稿
```

路径 B：素材页。

```text
进入「素材」tab
→ 浏览素材纸包
→ 点击素材包
→ 进入素材包详情
→ 查看非结构化素材纸
→ 点击单个素材
→ 素材被选中
→ 底部出现「添加到画布」
→ 点击添加
→ 如果已有画布：添加到当前画布
→ 如果无画布：创建默认 3:4 画布
→ 回到创作页编辑状态
```

素材页原则：

- 不做商城感。
- 不显示数量。
- 不突出商品卡片。
- 素材详情像一张真实素材纸。
- 点击单个素材是挑选，不是购买。

### 添加胶带流程

```text
编辑状态
→ 点击主工具栏「胶带」
→ 打开胶带面板
→ 展示胶带样式
→ 点击胶带
→ 胶带进入画布
→ 默认贴在照片角或画布中央
→ 用户可拖拽 / 旋转
→ 自动保存草稿
```

P0 提供 3-5 个胶带样式，可移动、旋转、删除、复制。

### 添加文字流程

P0 基础流程：

```text
编辑状态
→ 点击主工具栏「文字」
→ 创建默认文字图层
→ 进入文字编辑
→ 用户输入内容
→ 确认
→ 文字出现在画布
→ 用户可移动 / 删除
→ 自动保存草稿
```

P1 高级文字样式：

```text
选中文字图层
→ 打开文字工具面板
→ 调整字体预设
→ 调整字号
→ 调整颜色
→ 调整背景
→ 调整透明度
→ 支持多行文本
```

### 剪刀流程，P1

```text
编辑状态
→ 用户选中图片或素材图层
→ 点击主工具栏「剪刀」
→ 进入剪刀模式
→ 打开剪刀面板
→ 选择样式：直线 / 波浪 / 撕边
→ 应用到当前图层
→ 生成裁剪效果
→ 用户确认或取消
→ 自动保存草稿
```

P1 最小实现建议：

- 先做 1-2 种视觉效果。
- 优先直线裁切 / 撕边效果。
- 不做复杂自由路径裁剪。
- 不做精细蒙版编辑。

异常分支：

```text
未选中图层时点击剪刀
→ 提示「先选择一个图片或素材」
```

### 灵感页流程

当前 H5 已调整为：灵感图瀑布流 + 点击查看大图，不进入创作页。小程序 MVP 与此保持一致。

```text
进入「灵感」tab
→ 展示灵感图片瀑布流
→ 点击灵感卡片
→ 展开大图预览
→ 点击关闭或背景
→ 返回瀑布流
```

MVP 不做：

- 模板套用。
- 一键开始创作。
- 灵感详情说明页。
- 推荐素材包跳转。

### 草稿保存与恢复流程

自动保存：

```text
用户产生编辑行为
→ 防抖 800-1500ms
→ 保存 Draft JSON
→ 生成或更新草稿缩略图
→ 顶部状态显示「已保存」
```

恢复流程：

```text
进入创作页空状态 / 我的页
→ 查看最近草稿
→ 点击草稿
→ 加载 Draft JSON
→ 恢复画布与图层
→ 进入编辑状态
```

异常分支：

- 草稿资源缺失：提示「草稿部分素材丢失」，尽可能恢复可用图层。
- 草稿解析失败：提示「草稿打开失败」，保留草稿，不直接删除。

### 导出保存流程

```text
编辑状态
→ 点击「导出」
→ 进入导出预览
→ canvas 合成最终图片
→ 点击保存到相册
→ 检查相册权限
→ 生成临时图片
→ wx.saveImageToPhotosAlbum
→ 成功提示
→ 可继续编辑
```

授权失败分支：

```text
用户未授权相册
→ 弹出说明
→ 引导打开设置
→ 用户授权后重试保存
```

导出失败分支：

```text
canvas 合成失败 / 保存失败
→ 提示「保存失败，请重试」
→ 保留编辑状态
```

### 我的页流程

```text
进入「我的」
→ 展示最近草稿
→ 展示设置
→ 设置中仅保留清理缓存
→ 点击删除 icon
→ 清理临时素材和导出缓存
→ 提示「缓存已清理」
```

MVP 不做：

- 收藏素材。
- 完整作品库。
- 手账本。
- 文件夹。
- 云同步。
- 公开主页。
- 社区发布。

## 5. 异常与兜底状态清单

P0 必须覆盖：

- 无照片空状态。
- 无草稿空状态。
- 相册选择取消。
- 图片添加失败。
- 图片过大或加载失败。
- 无画布时添加素材。
- 未选中图层时点击图层工具。
- 草稿保存失败。
- 草稿打开失败。
- 导出中。
- 导出失败。
- 相册未授权。
- 保存相册失败。
- 网络素材加载失败。
- 灵感图片加载失败。

## 6. 技术验证 Spike 清单

总目标：

```text
选择图片
→ 进入 canvas
→ 拖拽 / 缩放 / 旋转
→ 添加素材 / 文字
→ 保存为草稿 JSON
→ 重新打开恢复
→ 导出到相册
```

建议周期：5-7 个工作日。

建议 Demo 页面：

```text
/pages/spike-editor/index
```

页面按钮：

- 选择图片。
- 添加胶带。
- 添加文字。
- 保存草稿。
- 恢复草稿。
- 导出相册。

画布能力：

- 点击选中。
- 拖动。
- 双指缩放旋转。
- 绘制选中框。

### Spike 1：canvas 渲染

验证内容：

- 创建固定比例画布：`3:4`、`1:1`、`9:16`。
- 渲染背景色。
- 渲染用户照片。
- 渲染纸张、胶带、贴纸。
- 渲染文字。
- 支持图层顺序。
- 支持旋转、透明度、阴影。
- 支持选中框绘制。

验收标准：

- 10 个图层以内渲染不卡顿。
- 图层位置、旋转、缩放表现正确。
- 文字能正常绘制。
- 图片资源能稳定加载。
- 切换比例后画布不变形。
- 选中框与图层位置基本一致。

产出：

- `renderLayer(layer)`。
- `renderDraft(draft)`。
- canvas 尺寸和 DPR 处理结论。
- 支持 / 不支持的 layer 属性清单。

### Spike 2：触控手势

验证内容：

- 单指拖拽图层。
- 双指缩放图层。
- 双指旋转图层。
- 点击选中图层。
- 点击空白取消选中。
- 图层命中检测。
- 多图层重叠时选中最上层。
- 拖动时实时重绘。
- 手势结束后保存状态。

验收标准：

- 单指拖动跟手。
- 双指缩放不跳动。
- 双指旋转角度稳定。
- 多图层能选中最上层。
- 操作 1 分钟无明显卡顿。
- 不误触页面滚动。
- iPhone 和安卓都能操作。

产出：

- `hitTest(x, y, layers)`。
- `gestureState` 结构。
- 单指 / 双指手势算法。
- setData 使用边界与性能建议。

### Spike 3：草稿 JSON 恢复

验证内容：

- 定义 Draft JSON。
- 保存图层列表。
- 保存画布比例。
- 保存图片路径。
- 保存素材路径。
- 保存文字内容和样式。
- 本地存储草稿。
- 重新进入页面恢复。
- 图片路径失效兜底。

最小 Draft：

```ts
type Draft = {
  id: string
  ratio: '3:4' | '1:1' | '9:16'
  width: number
  height: number
  background: string
  layers: Layer[]
  updatedAt: number
}

type Layer = {
  id: string
  type: 'image' | 'text' | 'sticker' | 'tape' | 'paper'
  x: number
  y: number
  width: number
  height: number
  rotation: number
  scale: number
  opacity: number
  zIndex: number
  source?: string
  text?: string
  style?: Record<string, any>
}
```

验收标准：

- 关闭页面后仍能恢复。
- 图层数量、顺序正确。
- 图片、素材、文字恢复正确。
- 位移、缩放、旋转恢复正确。
- 草稿 JSON 可版本化。
- 图片路径失效时不会白屏或崩溃。

产出：

- `saveDraft(draft)`。
- `loadDraft(id)`。
- `migrateDraft(draft)`。
- `Draft schema v1`。
- 图片资源持久化策略结论。

### Spike 4：图片导出

验证内容：

- canvas 合成最终图片。
- 按画布比例导出。
- 处理设备像素比。
- 导出高清图。
- 保存到相册。
- 相册授权失败兜底。
- 导出图片与编辑态视觉一致。
- 导出耗时统计。

验收标准：

- 成功保存到相册。
- 导出图片比例正确。
- 不糊，不明显失真。
- 无异常黑边、白边。
- 文字、素材、照片位置与编辑态一致。
- 导出耗时可接受，目标 2 秒内，复杂作品可放宽。
- 未授权时有明确提示和重试路径。

产出：

- `exportDraftToImage(draft)`。
- 导出尺寸策略。
- 相册授权处理结论。
- 导出失败原因分类。

### Spike 通过标准

通过：

- 能在真机上流畅编辑 5-10 个图层。
- 能稳定保存草稿并恢复。
- 能导出清晰图片到相册。
- 触控手感可接受。
- 没有发现小程序平台级不可绕过限制。

不通过：

- canvas 编辑频繁卡顿。
- 双指缩放旋转无法稳定。
- 导出图片质量不可接受。
- 草稿图片路径无法可靠恢复。
- 真机表现与开发者工具差异过大。

## 7. 小程序 MVP 详细开发计划

### 阶段 0：技术 Spike，5-7 个工作日

目标：

- 验证 canvas 渲染。
- 验证触控手势。
- 验证图片导出。
- 验证草稿 JSON 恢复。

验收门槛：

- 真机可流畅操作 5-10 个图层。
- 草稿可关闭后恢复。
- 导出图片比例正确、清晰。
- iPhone 和安卓至少各测一台。
- 没有发现小程序平台级不可绕过限制。

### 阶段 1：工程与基础页面，1 周

任务：

- 初始化微信小程序项目。
- TypeScript 配置。
- 目录结构。
- 环境配置：dev / test / prod。
- 全局状态管理。
- 页面路由。
- 本地存储工具。
- 图片资源工具。

## 11. 主要风险与缓冲

高风险：

1. 小程序 canvas 性能不足。
   - 缓解：限制图层数量、压缩图片、降低实时阴影、导出时再高清合成。

2. 双指手势不稳定。
   - 缓解：先做单指拖拽 + 简化缩放旋转，控制点操作后置。

3. 草稿图片路径失效。
   - 缓解：导入图片时复制到持久化本地文件，必要时上传云端。

4. 导出失败或模糊。
   - 缓解：单独导出 canvas，固定导出尺寸，真机多测。

5. P1 功能拖慢上线。
   - 缓解：高级文字和剪刀不阻塞 P0。

6. iOS 后续重做成本。
   - 缓解：schema / API / 素材 / 埋点从第一天平台无关。
